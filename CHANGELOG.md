# Changelog

## 0.1.0 — 2026-10-27

- WCAG 2.2 contrast grades (AA, AA large, AAA, AAA large, UI components).
- `fixContrast`: closest passing color in OKLCH, same hue, with gamut mapping; can adjust the background.
- CSS audit with custom properties, design-token audit (W3C / Style Dictionary, references).
- Color-vision simulation and palette confusion finder.
- Terminal, JSON, Markdown and HTML reports; `contrast-doctor` CLI.
